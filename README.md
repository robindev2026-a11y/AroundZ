# CoffeeCall

CoffeeCall is an activity-based meetup app for nearby spontaneous plans.

## Getting Started for Contributors

Welcome! To keep our users' data secure, the production `GoogleService-Info.plist` is **intentionally excluded** from this repository. If you want to run the app locally, you will need to point it to your own free Firebase project.

### How to run the app locally:
1. Go to the [Firebase Console](https://console.firebase.google.com/) and create a new free project.
2. Register a new iOS app in your project (the Bundle ID is `com.robindev.CoffeeCall` or whatever you prefer to set locally).
3. Enable **Firestore**, **Firebase Authentication** (Email/Password or Anonymous), and **Storage** in your Firebase project.
4. Download the `GoogleService-Info.plist` file generated by Firebase.
5. Place the `GoogleService-Info.plist` inside the `apps/frontend/Coffee_Call/App/` directory (it will be ignored by Git automatically).
6. Open `apps/frontend/Coffee_Call.xcodeproj` in Xcode and hit Run!

For more details on submitting PRs, please read our [CONTRIBUTING.md](CONTRIBUTING.md).
