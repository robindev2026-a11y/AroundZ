# AroundZ (formerly CoffeeCall) ☕️

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Swift](https://img.shields.io/badge/Swift-5.5+-orange.svg)](https://swift.org)
[![iOS](https://img.shields.io/badge/iOS-16.0+-blue.svg)](https://apple.com/ios)

AroundZ is an activity-based meetup app built natively for iOS. Instead of browsing profiles like a traditional networking or dating app, AroundZ focuses entirely on the **activity**. Users create nearby "Drifts" (spontaneous plans like grabbing coffee, walking a dog, or exploring a museum), and others in the area can request to join. 

Built with **SwiftUI** and powered by **Firebase**.

## Features
- **Local Radar**: Discover activities happening within a 10km radius of your location.
- **Create Drifts**: Host your own activities with customizable vibes, capacities, and time slots.
- **Join & Chat**: Request to join an activity. Once approved, coordinate the meetup via async chat.
- **Modern UI**: Built with a custom glassmorphic SwiftUI design system utilizing dynamic colors and micro-animations.

## Getting Started for Contributors

Welcome to the project! To keep our users' data secure, the production `GoogleService-Info.plist` is **intentionally excluded** from this repository. If you want to run the app locally, you will need to point it to your own free Firebase project.

### 1. Requirements
* Xcode 15.0+
* iOS 16.0+
* A free [Firebase Account](https://firebase.google.com/)

### 2. Local Firebase Setup
1. Go to the [Firebase Console](https://console.firebase.google.com/) and create a new free project.
2. Register a new iOS app in your project. You can use any Bundle ID, but matching `com.robindev.CoffeeCall` is recommended.
3. Enable **Firestore**, **Firebase Authentication** (Email/Password or Anonymous), and **Storage** in your Firebase project.
4. Download the `GoogleService-Info.plist` file generated by Firebase.
5. Place the `GoogleService-Info.plist` inside the `apps/frontend/Coffee_Call/App/` directory (it will be ignored by Git automatically thanks to our `.gitignore`).
6. Open `apps/frontend/Coffee_Call.xcodeproj` in Xcode and hit Run!

## Architecture

This project strictly follows the **MVVM (Model-View-ViewModel)** architectural pattern. 
* **Models**: Pure data representations and Domain enums (`Drift`, `ActivityType`, etc.).
* **ViewModels**: State management, business logic, and Firebase service interaction.
* **Views / Screens**: Pure UI, built primarily with generic composable components without tight coupling.
