# Design Research Prompt for ChatGPT

Copy and paste this prompt into ChatGPT to get design reference recommendations for CoffeeCall.

---

## Prompt to Use:

```
PROJECT BRIEF: CoffeeCall MVP

CoffeeCall is an activity-based meetup platform (NOT dating app). Users post activities 
(coffee, movies, jogging, etc.) → nearby people get notified (10km radius) → they accept → 
coordinate via in-app messages → meet up.

Core characteristics:
- Local focus (10km radius notifications)
- Activity-based (not social network)
- Quick actions (post → discover → accept → message)
- Community-driven (reputation through activity)
- Lightweight/simple (MVP, not feature-heavy)
- Mobile-first (iOS)

DESIGN RESEARCH REQUEST:

I need design references/inspiration for the CoffeeCall app. Please research and recommend:

1. SIMILAR APPS TO ANALYZE:
   - List 5-10 apps with similar UX patterns (meetup, activity discovery, local focus)
   - For each: name, why it's relevant, what design patterns to study
   - Example: Meetup.com (activity discovery), Bumble BFF (social matching), Nextdoor (local community)

2. DESIGN STYLE RECOMMENDATIONS:
   - What visual style fits an activity-based meetup app?
   - Modern + minimal vs. colorful + fun?
   - Professional + trustworthy vs. casual + approachable?
   - Recommendation with reasoning

3. COLOR PALETTE SUGGESTIONS:
   - Suggest 2-3 different color palettes for CoffeeCall
   - Each palette should have: primary color, secondary, accent, neutral colors
   - Include hex codes or descriptions
   - Explain the mood/feeling each palette conveys
   - Which palette best fits "local activity discovery"?

4. COMPONENT STYLE RECOMMENDATIONS:
   - How should buttons look? (rounded, sharp, modern, playful?)
   - How should cards look? (shadowed, flat, outlined?)
   - What typography style? (geometric, friendly, professional?)
   - Rounded vs sharp corners?

5. LAYOUT PATTERNS:
   - What layout works best for activity discovery? (list, grid, map?)
   - Tab bar or bottom navigation?
   - How to show nearby posts effectively?
   - Best UX for post creation flow?

6. REFERENCE APPS TO STUDY:
   - List specific apps to look at for design inspiration
   - What to study in each (color, typography, components, layout)
   - Links or where to find them (App Store, website, Dribbble, Behance)

7. ICON & IMAGE STYLE:
   - Icon style recommendations (outlined, filled, duotone)
   - Should we use photography or illustrations?
   - Image sources (Unsplash, Pexels, custom illustrations)

8. ACCESSIBILITY CONSIDERATIONS:
   - Color contrast recommendations for accessibility
   - Touch-friendly component sizes
   - Dark mode consideration?

Please provide detailed recommendations with reasoning so I can make informed design 
decisions for the MVP.
```

## Alternative (Shorter) Version:

If you want a quicker prompt, use this:

```
I'm designing an app called CoffeeCall - an activity-based meetup platform where users 
post local activities (coffee, movies, jogging) → nearby people (10km radius) discover 
them → accept → message → meet up. Think Meetup.com meets Tinder's swipe simplicity, 
but focused on activities, not dating.

Please recommend:
1. 5-10 similar apps I should study for design patterns
2. Best visual style (modern/minimal vs colorful/fun) with reasoning
3. 3 different color palette options with hex codes
4. Component style suggestions (button, card, input design)
5. Layout patterns for activity discovery
6. Icon and image style recommendations

Format: Clear sections with explanations for each recommendation.
```
