## 2. Cross-Cutting UI Issues

### 2A. Bottom Navigation Style
- **Android:** Pill-shaped selected state, no text labels
- **iOS:** Text labels under all icons, colored icon for selected
- **Fix:** Redesign Android bottom nav to use text labels under icons, matching iOS `FloatingTabBar.swift`

### 2B. "Sign out" Button Placement
- **Android:** Appears in header of EVERY screen (Drifts, Chats, Profile)
- **iOS:** Only in Profile > Account section
- **Fix:** Remove "Sign out" from all Android headers. Keep only in Profile Account section.

### 2C. Header Icon Layout
- **Android:** Mixed — some screens have search bar below, some have icons in header
- **iOS:** Consistent — bell/search/filter icons inline in header
- **Fix:** Standardize Android headers to match iOS inline icon layout

## 3. Functional Gaps

### 3A. Filter Sheet — Missing Time & Activity Type Filters
- **Android filter:** Distance only
- **iOS filter:** Distance + Time + Activity Types
- **Fix:** Add Time chips (All, Today, Tomorrow, This Weekend) and Activity Types grid to Android `DriftsFilterSheet`
- **Files:** `apps/android/app/src/main/java/com/coffeecall/app/feature/drifts/DriftsScreen.kt` (filter sheet composable)

### 3B. Active Filter Badge
- **Android:** No indicator when filters are active
- **iOS:** Badge "1" on filter icon
- **Fix:** Track active filter count in `DriftsViewModel`, render badge on filter icon
- **Files:** `apps/android/app/src/main/java/com/coffeecall/app/feature/drifts/DriftsViewModel.kt`, `DriftsScreen.kt`

### 3C. "Joined" vs "Hosting" Button States
- **Android:** "Joined" (teal) for joined drifts, "Manage" for hosted
- **iOS:** "Joined" (peach) for joined, "Hosting" (purple) for hosted
- **Fix:** Align button text and colors: "Joined" → peach, "Manage" → "Hosting" in purple
- **Files:** `apps/android/app/src/main/java/com/coffeecall/app/feature/drifts/DriftsScreen.kt`

### 3D. Drift Detail — Missing Summary Grid
- **Android:** Shows hero image + text description
- **iOS:** Shows summary grid cards (Date, Location, Distance, Participants)
- **Fix:** Add summary grid section to Android `DriftDetailScreen`
- **Files:** `apps/android/app/src/main/java/com/coffeecall/app/feature/driftDetail/DriftDetailScreen.kt`

### 3E. Drift Detail — Missing Share/Bookmark/Calendar Actions
- **Android:** Not visible in detail header
- **iOS:** Share, bookmark, calendar reminder buttons in header
- **Fix:** Add action buttons to Android detail header
- **Files:** `apps/android/app/src/main/java/com/coffeecall/app/feature/driftDetail/DriftDetailScreen.kt`
