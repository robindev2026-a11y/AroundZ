# iOS UI Alignment Plan — Android Parity

## Goal
Align Android UI to match iOS based on side-by-side screenshot comparison. Focus on bottom nav, profile, chats, settings rows, and visual details.

## Scope
- **In scope:** `apps/android/` presentation layer — navigation, screens, components
- **Out of scope:** iOS code, repositories, domain models

---

## 1. Bottom Navigation Bar — Match iOS Glass Style

**File:** `core/navigation/CoffeeCallApp.kt`

**Current Android:** Active tab has solid `CoffeePrimary` pill background with white icon.
**iOS:** Active tab has NO filled pill — just colored icon + text label. The bar itself is the glass element.

**Changes:**
- Remove the solid `CoffeePrimary` background on selected tabs (lines ~556-606)
- Selected state: colored icon (`CoffeePrimary`) + colored label (`CoffeePrimary`), no background fill
- Unselected state: gray icon (`CoffeeMuted`), no label text (iOS hides unselected labels)
- Keep the glass bar container as-is (semi-transparent surface + border + shadow)
- Create button stays as-is (it matches iOS)

**Lines to modify:** ~556-606 (tab item composable)
