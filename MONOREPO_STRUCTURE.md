## Folder Purposes

### Root Level (Config & Documentation)
- **CLAUDE.md** — Project context for Claude Code
- **AGENTS.md** — Standardized AI tool configuration
- **.claude/settings.json** — Permissions + project rules
- **.cursorrules** — Cursor IDE configuration
- **.claudeignore** — Files to exclude from AI context

### `/Planning` (Strategy & Requirements)
- **spec.md** ⭐ — Single source of truth for what to build
- **architecture.md** — How to build it
- **decisions.md** — Why we made architectural choices
- **context.md** — Session-to-session continuity

**Used by:** Claude (planning), Codex (prompt generation)

### `/Design` (Visual & Component Specs)
- **design-tokens.md** ⭐ — Reusable design values (used in code generation)
- **screens.md** — What each screen looks like
- **component-specs.md** — How each component works

**Used by:** Codex (prompt generation), Antigravity IDE (code generation)

### `/Prompts` (AI Generation Instructions)
- **VERSIONING.md** — How to version prompts (semantic versioning)
- **production/** — Codex-generated prompts ready for code generation
  - `backend-prompt.v1.0.0.md` — Instructions for Firebase functions
  - `frontend-prompt.v1.0.0.md` — Instructions for SwiftUI iOS code
  - `integration-prompt.v1.0.0.md` — Instructions for API integration

**Used by:** Codex (reads spec to generate), Antigravity IDE (reads prompts to generate code)

### `/apps/frontend` (iOS Code)
- **src/screens/** — UI screen implementations
- **src/components/** — Reusable UI components
- **src/services/** — Firebase, geolocation, API calls
- **src/models/** — Data structure definitions

**Generated by:** Codex + Antigravity IDE  
**References:** `/Design/design-tokens.md`, `/Design/screens.md`, `/Planning/spec.md`

### `/apps/backend` (Firebase Cloud Functions)
- **functions/src/triggers/** — HTTP endpoints and Cloud Function triggers
- **functions/src/handlers/** — Business logic for each endpoint
- **functions/src/services/** — Firebase integration, geohashing
- **firestore.rules** — Database security rules
- **firestore.indexes.json** — Query optimization indexes

**Generated by:** Codex + Antigravity IDE  
**References:** `/Planning/architecture.md`, `/Planning/spec.md`, `/Planning/api-spec.md`

## Workflow

### Phase 1: Planning (✅ Complete)
- ✅ spec.md written
- ✅ architecture.md finalized
- ✅ decisions.md documented
- ✅ design-tokens.md complete

### Phase 2: Design (⏳ Next)
- ⏳ Finalize Figma/Pencil mockups
- ⏳ Complete component-specs.md
- ⏳ Update accessibility.md

### Phase 3: Prompt Generation (⏳ Then)
- ⏳ Codex reads spec + design
- ⏳ Codex generates backend-prompt.v1.0.0.md
- ⏳ Codex generates frontend-prompt.v1.0.0.md
- ⏳ Upload prompts to `/Prompts/production/`

### Phase 4: Code Generation (⏳ Then)
- ⏳ Antigravity IDE reads backend-prompt.v1.0.0.md
- ⏳ Antigravity IDE generates `/apps/backend/` code
- ⏳ Antigravity IDE reads frontend-prompt.v1.0.0.md
- ⏳ Antigravity IDE generates `/apps/frontend/` code

### Phase 5: Verification (⏳ Finally)
- ⏳ Claude verifies code against spec
- ⏳ Run tests
- ⏳ Deploy

## How to Use This Structure

### For Claude (Planning & Oversight)
```
1. Read /Planning/spec.md
2. Read /Planning/architecture.md
3. Check /Planning/context.md (last session)
4. Review /Design/design-tokens.md
5. Verify code against acceptance criteria
```

### For Codex (Prompt Generation)
```
1. Read /Planning/spec.md (requirements)
2. Read /Planning/architecture.md (design)
3. Read /Design/design-tokens.md (UI values)
4. Read /Design/screens.md (UI specs)
5. Generate backend-prompt.v1.0.0.md → /Prompts/production/
6. Generate frontend-prompt.v1.0.0.md → /Prompts/production/
```

### For Antigravity IDE (Code Generation)
```
1. Read /Prompts/production/backend-prompt.v1.0.0.md
2. Generate code into /apps/backend/
3. Read /Prompts/production/frontend-prompt.v1.0.0.md
4. Generate code into /apps/frontend/
5. Reference /Design/design-tokens.md during generation
```

## Commands

**Build Frontend:**
```bash
cd apps/frontend
npm install
npm run build
```

**Build Backend:**
```bash
cd apps/backend
npm install
firebase deploy --only functions
```

**Test:**
```bash
npm test
```

**Firebase Emulator (Local Testing):**
```bash
cd apps/backend
firebase emulators:start
```
