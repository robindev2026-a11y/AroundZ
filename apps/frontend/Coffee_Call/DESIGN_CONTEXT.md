# CoffeeCall Design Context

CoffeeCall is a premium mobile app for spontaneous in-person social meetups nearby.

## Product Direction

- Discover people and activities nearby
- Join spontaneous meetups
- Chat before meeting
- Build trust for meeting strangers safely
- Make the app feel alive, warm, and human

## Visual Direction

- Mobile-first and premium
- Warm neutral backgrounds
- Modern mint accents
- Soft lavender highlights
- Slate typography
- Large avatars
- Layered cards
- Rounded corners
- Soft shadows
- Subtle gradients
- Generous spacing

## Color Palette

- Primary Accent: `#53B8A6`
- Primary Accent Hover: `#3D8D7A`
- Highlight: `#8E7DBE`
- Primary Text: `#243447`
- Secondary Text: `#5F6368`
- Background: `#F6F1EB`
- Card Surface: `#FFFDF9`
- Secondary Surface: `#F4F4F8`
- Border: `#E7DED4`
- Optional CTA Accent: `#E88C6B`

## Screen Priorities

1. Discover
2. Activity Details
3. Messages
4. Onboarding
5. Profile
6. Create Meetup
7. Notifications
8. Map View
9. Empty States
10. Create Meetup Success
11. Verification and Trust

## Do Not Design It Like

- A coffee app
- A dating app
- Enterprise SaaS
- A task manager
- An event dashboard
- A generic blue-and-white startup UI

## Core Emotion

Spontaneous, human, safe, social, alive, and premium.
