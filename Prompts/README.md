# Prompts Directory

This directory contains prompts generated by Codex that will be fed to Ambiglytics for code generation.

## Files

### backend-prompt.md
Prompt for Ambiglytics to generate backend code:
- Firebase Cloud Functions
- Firestore data models and security rules
- Authentication logic
- Notification triggers

### frontend-prompt.md
Prompt for Ambiglytics to generate frontend code:
- UI components (SwiftUI for iOS)
- Screen layouts
- Navigation structure
- State management

### integration-prompt.md
Prompt for Ambiglytics to generate integration layer:
- API calls to Firebase
- Data synchronization
- Real-time updates
- Error handling

---

## Workflow

1. **Planning** → Architecture + Features defined (see `/Planning`)
2. **Design** → Mockups + Design system defined (see `/Design`)
3. **Codex** → Generates detailed prompts (saved here)
4. **Ambiglytics** → Reads prompts, generates code
5. **Verification** → Code tested against plan
